# Fingerprint diagnosis and comparison with the 2007 SEA paper

Recorded on 2026-11-08, before the subsequent [ChEMBL parameter validation](chembl37-parameter-validation.md). That validation adopted a separate Morgan/0.45 reference; the measurements below continue to describe the original path-fingerprint reference.

The complete machine-readable measurements are in
[paper-comparison-results.json](paper-comparison-results.json), generated by
[scripts/compare_paper.py](../scripts/compare_paper.py). The service's fingerprints,
reference datasets, calibration models, and stored predictions were not changed.

## Why the reported Tanimoto values differ

Query: `COc1ccc2[nH]cc(c2c1)C(CC)CN`

Reference: `COc1ccc2[nH]cc(CCN)c2c1`

The following are actual calculations in the locked RDKit 2026.09.2 environment:

| Fingerprint | Shared on bits | Union of on bits | Binary Tanimoto |
| --- | ---: | ---: | ---: |
| Current RDKit path, 2,048 bits, paths 1–7 | 506 | 616 | **0.82142857** |
| Morgan radius 2, 2,048 bits, no chirality or count simulation | 24 | 44 | **0.54545455** |
| Morgan radius 1, 2,048 bits | 17 | 26 | 0.65384615 |
| Morgan radius 3, 2,048 bits | 27 | 61 | 0.44262295 |

Both calculations use the same binary Tanimoto formula, `shared_bits / union_bits`.
For this pair, every on bit in the reference path fingerprint also occurs in the
query fingerprint. Circular fingerprints encode atom neighborhoods; substitution
changes those neighborhoods and their identifiers. The two representations
therefore produce different overlaps. See the [RDKit fingerprint documentation](https://www.rdkit.org/docs/GettingStartedInPython.html#morgan-fingerprints-circular-fingerprints).

Neither molecule changes chemically during this project's standardization:
Cleanup, FragmentParent, Uncharger, and canonical isomeric SMILES generation.
The canonical strings are `CCC(CN)c1c[nH]c2ccc(OC)cc12` and
`COc1ccc2[nH]cc(CCN)c2c1`. The observed difference can be reproduced by changing
only the fingerprint; salt removal, neutralization, or SEA significance estimation
is not needed to explain it.

Morgan radius 2, approximately the ECFP4 representation, reproduces the reported
0.5455. The same value occurs at 1,024, 2,048, and 4,096 bits for this particular
pair. One matching pair cannot identify the other implementation's bit length,
standardization, toolkit, or complete settings. The source of the reported score
has not yet been confirmed.

## Which original implementation is being compared

The [2007 paper](https://doi.org/10.1038/nbt1284) used Daylight fingerprints and
MDDR activity classes. This project uses RDKit path fingerprints and filtered
ChEMBL ligand sets. RDKit describes its path fingerprint as Daylight-like;
this does not establish identical bits or Tanimoto values.

Later SEA applications have also used ECFP4. For example, the Methods of this
[2021 primary research paper](https://www.nature.com/articles/s41467-021-23165-1)
explicitly describe ECFP4 queries to the SEA web application. That does not
establish the settings of a particular current server result. A comparison with
that server and a reproduction of the 2007 paper are different experiments.

| Component | 2007 comparison | Current service |
| --- | --- | --- |
| Molecular representation | Daylight fingerprints | RDKit path fingerprints |
| Reference data | MDDR activity classes | ChEMBL 37, human single proteins, configured assay/potency filters |
| Pair aggregation | Sum of qualifying Tanimoto values | Sum at or above the configured threshold |
| Null calibration | Original MDDR background; published example threshold 0.57 | Recalibrated on each dataset; held-out KS selection |
| Tail calculation | Standardized extreme-value model in Supplementary Methods | Fitted Gumbel when eligible, otherwise finite Monte Carlo |
| Multiple comparisons | 246 × 246 in the published matrix | Number of targets searched, or 1 for a two-set job |

A single-molecule query always uses the current Monte Carlo branch when its raw
score is positive. With 999 trials its minimum p-value is 0.001. The paper's tiny
E-values cannot be expected from that branch. Threshold 0.57 and the MDDR fitted
coefficients must not be copied to Morgan/ChEMBL as validated parameters.
For zero raw scores, the service returns the exact nonnegative-null result `p=1`;
the original continuous tail approximation can give a different value. The
statistical replay below applies the original tail to every published row and
does not substitute the service's zero-score or Monte Carlo branches.

## Comparison actually performed

The official [Supplementary Data ZIP](https://static-content.springer.com/esm/art%3A10.1038%2Fnbt1284/MediaObjects/41587_2007_BFnbt1284_MOESM65_ESM.zip)
contains one XLS workbook with three sheets: protein mappings, sizes for 246
activity classes, and **60,516 ordered comparisons** with published raw score,
Z-score, E-value, identities, and maximum Tanimoto. The workbook contains no
ligand structures, per-pair fingerprints, or per-class ligand memberships.
The script verifies the ZIP SHA256 and complete 246 × 246 pair coverage.

The statistical replay uses those published raw scores as inputs. It does not
recompute them from molecules or refit the MDDR background. The coefficients
come from [Supplementary Table 5](https://static-content.springer.com/esm/art%3A10.1038%2Fnbt1284/MediaObjects/41587_2007_BFnbt1284_MOESM63_ESM.pdf):

```text
n = query_size * reference_size
mu = 0.000424 * n
sigma = 0.00449 * n**0.665
z = (raw_score - mu) / sigma
p = 1 - exp(-exp(-z*pi/sqrt(6) - EulerGamma))
E = p * 60,516
```

These coefficients and the standardized tail are used only for this comparison.
They do not replace the current ChEMBL model.

| Check | Measured result | What it supports |
| --- | --- | --- |
| Raw-score aggregation, two fingerprints × four thresholds | All 8 scores/counts match an independent Python bit-set calculation; maximum score error 0 | Correct implementation on the six-molecule control fixture |
| Standardized tail, Z = 0, 20, 28, 119, 578, 1000 | Maximum absolute log-p error versus 100-digit Decimal arithmetic: 1.14 × 10⁻¹³ | Stable tail evaluation, including underflowing p-values |
| Production Gumbel branch configured to the original standardized tail | 17,181 eligible positive-score comparisons; maximum absolute log-E difference from the original-tail function: 9.10 × 10⁻¹³ | The production tail can represent the same mathematical distribution |
| Published Z → E | 60,308 / 60,413 nonzero E-values agree within 1%; median relative error 0.000200% | Broad agreement with the published statistical transform |
| Published raw score → Z → rank | Across all 246 query classes: top-1 agreement 100%; mean top-5 and top-10 set overlaps 100%; mean Spearman 0.99999793 | Nearly identical statistical ordering from the supplied original raw scores |

The production-branch check deliberately supplies the standardized Gumbel location
`-EulerGamma*sqrt(6)/pi` and scale `sqrt(6)/pi`. It excludes zero raw scores and
sets smaller than 10, for which production deliberately uses other branches.
It is a mathematical configuration check, not a test of the fitted ChEMBL model.

Ranking excludes each class's self-match. Published Z-scores retain the ordering
of entries whose E-values were saved as zero. Top-5/10 overlap measures membership,
not equality at each rank position. Both sides use class ID to break Z-score ties.
The two directions of a symmetric pair are counted separately, as in the workbook;
these measurements are not independent biological samples or confidence intervals.

### Numerical discrepancies are retained

The largest relative Z → E discrepancy is **46.84%**, so exact numeric replication
is not claimed. In the 392 nonzero comparisons with `20 <= Z < 30`, the discrepancy
is consistent with loss of precision in subtracting a value close to 1. For
example, a published E-value of `6.7186e-12` is approximately
`60,516 * 2**-53`, a float64 subtraction step. Rounded published Z-scores and very
small floating-point values also limit comparison. There are 103 published zero
E-values; these are treated as censored and excluded from relative-error metrics.
The replay preserves their finite log E-values.

Using the rounded raw-score coefficients also introduces differences: the median
absolute Z error is 0.00813, the 95th percentile is 0.04455, and the maximum is
57.08167 on a published Z of 11,396. These errors can matter greatly after
exponentiation, even when ranks are stable.

The DHFR/TS example makes this distinction concrete:

| Calculation from the published raw score 772.25 and sizes 216 × 253 | Z | E |
| --- | ---: | ---: |
| Original XLS row | 117.57 | 1.1057 × 10⁻⁶¹ |
| Stable tail using the XLS Z | 117.57 | 1.10711 × 10⁻⁶¹ |
| Recompute Z using Table 5's rounded coefficients | 117.97624 | 6.57532 × 10⁻⁶² |
| Supplementary Methods' approximate example | approximately 119 | approximately 1.77 × 10⁻⁶² |

The [Supplementary Methods](https://static-content.springer.com/esm/art%3A10.1038%2Fnbt1284/MediaObjects/41587_2007_BFnbt1284_MOESM64_ESM.pdf)
explicitly note accumulated approximation error versus the Results' E-value.
Its intermediate example mean, 12.241, also differs from directly applying the
printed coefficient to 54,648 (`mu = 23.170752`). The comparison records these
differences instead of adjusting constants to force a match.

## Repeating the comparison

From the repository root:

```bash
pixi install --locked -e paper-validation
pixi run --locked -e paper-validation python scripts/compare_paper.py --download --output var/paper-comparison.json
```

The optional Pixi environment adds `xlrd` for the original XLS workbook. The first
run downloads the official ZIP to `.cache/paper-comparison/data.zip`; subsequent
runs reuse and verify it. Alternatively, supply an existing ZIP with
`--supplement /path/to/41587_2007_BFnbt1284_MOESM65_ESM.zip`. No credentials or
running services are needed. No prediction is submitted to an external server.
The original workbook is not redistributed in this repository.

## What remains unproven

The result supports agreement of the aggregation and statistical transformations
within the stated checks. It **does not demonstrate equivalent target-prediction
accuracy or a reproduction of the paper's biological discoveries**. That requires
the original ligand memberships and structures, matching Daylight settings and
preprocessing, the original background sampling inputs, and an independent test
set. Those chemical inputs were not found in the official supplement.

A modern ChEMBL comparison should freeze the same release, filters, structures,
and scaffold or time split; generate path and Morgan representations; calibrate
each representation on training data only; then compare target rankings and
known-target retrieval on the same held-out queries. Prospective accuracy requires
independent assays. Substituting Morgan alone to match this one pair would not
validate the model, and would require rebuilt fingerprints and calibration.
