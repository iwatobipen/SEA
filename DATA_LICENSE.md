# Data attribution

The manually constructed synthetic chemical groups in `sea.cli.demo` are dedicated to the public domain under CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/ . They are not biological target annotations.

ChEMBL data, including redistributed curated derivatives, uses CC BY-SA 3.0: https://creativecommons.org/licenses/by-sa/3.0/ . The database builder stores the source URL, release, source checksum and attribution in each dataset manifest. Preserve these when distributing a built dataset. ChEMBL's data license is distinct from the MIT software license.

ChEMBL: https://www.ebi.ac.uk/chembl/
License information: https://chembl.github.io/chembl-licensing/

No original paper figures or commercial MDDR data are included.
